# 渠道管理统计看板需求

## 1. 入口与默认展示

入口位于“众包招募管理 → 招募渠道管理”。页面增加“渠道概览”和“渠道管理统计看板”两个页签：渠道概览展示现有渠道汇总表，统计看板展示渠道在不同项目、招募单上的贡献。“渠道管理”配置按钮保持原有操作。

进入统计看板时，默认按渠道汇总，筛选条件为累计申请、全部项目、全部渠道、全部招募单状态，按通过人次降序。页面显示统计截至日、时区及T+1标识。

## 2. 展示数据

顶部展示申请人次、通过人次、审核通过率、待审核人次。申请人次下显示覆盖项目数、招募单数；通过人次下显示当前范围去重后的通过用户数；审核通过率下显示已审核人次；待审核下显示申请转通过率。

主表提供“按渠道汇总”和“按项目汇总”两种视图，字段如下：

| 字段 | 展示规则 |
|---|---|
| 渠道名称 / 项目名称 | 按渠道视图展示渠道名；按项目视图展示项目名、项目编号和领域 |
| 申请人次 | 当前行范围内的有效申请记录数 |
| 通过人次 | 当前行已审核通过的申请记录数 |
| 待审核人次 | 当前行尚未完成审核的申请记录数 |
| 审核通过率 | 通过人次 ÷（通过人次 + 拒绝人次） |
| 通过贡献 | 当前行通过人次 ÷ 当前筛选范围总通过人次 |
| 操作 | “查看明细”，打开当前行关联的招募单明细抽屉 |

主表不展示“项目/招募单”或“渠道/招募单”组合数量列。表头下固定展示当前筛选合计行；总量按完整筛选结果计算，不随分页或行展开变化。

展开表展示对应的项目或渠道，以及招募单数、申请人次、通过人次、审核通过率、内部贡献、“招募单明细”操作。内部贡献以当前父行通过人次为分母。

## 3. 必要定义

- **有效申请**：按“招募单ID × 用户ID”确定唯一记录；同一用户在同一招募单只计一次，状态取统计截至日的最新有效申请状态。跨招募单累计为人次。
- **通过、拒绝、待审核**：分别对应审核通过、审核拒绝和尚未完成审核的申请；已审核人次等于通过加拒绝。
- **通过用户数**：在当前筛选范围内，对通过申请的用户ID去重。
- **申请转通过率**：通过人次 ÷ 申请人次，分母包含待审核申请。
- **招募单数**：当前统计范围内至少有一条有效申请的去重招募单ID数量。
- **渠道归因**：使用提交申请时记录的渠道ID；来源缺失统一归入“未归因”，并计入总量和占比分母。项目取招募单所属项目。
- **时间**：按申请提交时间筛选，时区为UTC+0；审核状态取统计截至日快照，数据按T+1更新。
- **数值格式**：数量用千分位整数；比率保留1位小数；分母为0时显示“—”。

## 4. 筛选与搜索

支持累计申请、近30天、近7天，项目、渠道、招募单状态和关键词搜索。关键词匹配渠道名、项目名/编号、招募单名/编号。多个条件取交集；指标、主表、展开表、抽屉和导出均使用同一筛选结果。

修改筛选或搜索后，返回第1页并收起展开行。切换按渠道/按项目汇总时保留筛选和主表排序，返回第1页并收起展开行。“重置”恢复默认筛选、通过人次降序和第1页。

## 5. 排序与Tooltip

主表的申请人次、通过人次、待审核人次、审核通过率、通过贡献支持排序；展开表的招募单数、申请人次、通过人次、审核通过率、内部贡献支持排序。

默认按通过人次降序。点击一个新的排序字段时先按降序，再次点击该字段切换升序；表头用箭头标识当前排序字段和方向。主表排序作用于全部筛选结果，再进行分页；展开表排序仅作用于当前父行，不改变主表及其他展开行。数值相同时按通过人次、申请人次降序，再按名称升序；无分母的比率排在末尾。

顶部指标、主表及展开表指标旁增加说明图标。鼠标悬停、键盘聚焦或点击图标时，显示该指标的统计对象、去重规则或计算公式；贡献占比还要说明分母范围。说明图标与排序按钮独立，点击说明不触发排序。

## 6. 点击与下钻

- 点击行首“+”或渠道/项目名称，展开下一层贡献；再次点击收起。允许同时展开多行。
- 按渠道汇总时，展开该渠道在各项目的贡献；按项目汇总时，展开该项目中各渠道的贡献。
- 点击主表“查看明细”，右侧抽屉展示当前渠道或项目下的招募单×渠道记录；点击展开表“招募单明细”，抽屉限定为当前项目×渠道。
- 抽屉展示招募单名称、编号、所属项目、招募单状态、渠道、申请、通过、待审核、审核通过率及顶部合计。
- 点击关闭按钮、遮罩或Escape关闭抽屉，保留原来的筛选、排序、展开状态和页码。

## 7. 导出与结果状态

主表每页10行，合计行不占分页数量。导出当前筛选结果的全部数据，按当前排序输出，包含统计截至日、汇总维度、筛选条件、指标和占比分母。抽屉可导出当前明细。

没有匹配记录时显示空结果和重置入口，并禁用导出。零申请渠道保留在渠道汇总中，指标显示0，比率按零分母规则展示，展开和明细入口禁用。
