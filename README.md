# 渠道统计：必要需求点

1. **入口**：在“按领域查看、招募单排行”后增加“渠道统计”。
2. **汇总视图**：提供“按渠道汇总”和“按项目汇总”，展示申请人次、通过人次、待审核人次、审核通过率、通过贡献及覆盖项目/渠道/招募单数量。
3. **行内下钻**：渠道行展开各项目贡献，项目行展开各渠道贡献；可查看当前项目与渠道关联的招募单。
4. **筛选**：支持累计、近30天、近7天，以及项目、渠道、招募单状态、关键词；筛选同步作用于指标、汇总表、下钻和导出。
5. **统计口径**：申请按“招募单ID×用户ID”去重后累计为人次；通过用户按当前范围去重；审核通过率=通过÷（通过+拒绝）；申请转通过率=通过÷申请。
6. **归因与占比**：每次申请归属一个项目、招募单、渠道；渠道取提交申请时记录的来源，来源缺失计入“未归因”。主表贡献以当前筛选的总通过人次为分母，展开贡献以父行通过人次为分母。
7. **表格操作**：默认按通过人次降序，支持指标排序、分页；切换汇总维度保留筛选。
8. **导出与空结果**：导出当前筛选范围内的全部汇总结果，包含统计截至日、筛选条件和指标；空结果提供重置入口，零分母比率显示“—”。

统计时间按UTC+0、T+1；按申请时间筛选，审核状态取统计截至日快照。
