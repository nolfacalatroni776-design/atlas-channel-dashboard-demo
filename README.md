# 渠道管理统计看板需求

## 1. 入口与默认展示

入口位于“众包招募管理 → 招募渠道管理”，提供“渠道概览”和“渠道管理统计看板”两个页签。“渠道管理”配置按钮保持原有操作。

看板默认按渠道汇总，范围为累计、全部项目、全部渠道、全部招募单状态，按通过人次降序。页面显示统计截至日、UTC+0及T+1标识。

## 2. 展示数据

顶部依次展示注册人数、申请人次、通过人次、审核通过率、待审核人次。注册人数标注“首次注册用户（按用户ID去重）”；申请人次下展示覆盖项目数、招募单数；通过人次下展示去重通过用户数；审核通过率下展示已审核人次；待审核下展示申请转通过率。

| 区域 | 字段 | 展示规则 |
|---|---|---|
| 主表 | 渠道名称 / 项目名称 | 渠道视图展示渠道名；项目视图展示项目名、编号和领域 |
| 主表 | 注册人数 | 当前行来源范围内，在统计期完成首次注册的去重用户数 |
| 主表 | 申请人次、通过人次、待审核人次 | 当前行申请范围内对应状态的有效申请记录数 |
| 主表 | 审核通过率 | 通过人次 ÷（通过人次 + 拒绝人次） |
| 主表 | 操作 | “查看明细”打开当前渠道或项目下的招募单×渠道抽屉 |
| 展开表 | 项目 / 渠道、招募单数、注册人数、申请人次、通过人次、审核通过率、操作 | 渠道展开项目，项目展开渠道；操作为“招募单明细” |

主表及展开表均为7列。表头下固定展示当前筛选合计行，合计按完整筛选结果计算，不随分页和行展开变化。

## 3. 指标定义与来源归因

- **注册人数**：统计期内完成首次注册的用户数，按用户ID去重，包含注册后尚未申请的用户。同一账号只计一次，重复登录及后续申请不新增注册人数。
- **注册来源**：取首次注册完成时记录的来源渠道ID和来源招募单ID，项目取该来源招募单所属项目。项目、渠道、招募单状态和搜索条件按该来源记录筛选。
- **有效申请**：按“招募单ID × 用户ID”确定唯一有效申请，状态取统计截至日的最新有效状态；跨招募单累计为人次。申请使用提交申请时记录的渠道与所属招募单。
- **通过、拒绝、待审核**：分别对应审核通过、审核拒绝和尚未完成审核的有效申请；已审核人次=通过+拒绝。
- **通过用户数**：在当前申请范围内，对审核通过的用户ID去重。
- **申请转通过率**：通过人次 ÷ 申请人次，分母包含待审核申请。
- **招募单数**：当前范围内发生注册或有效申请的去重招募单ID数量。
- **时间**：注册人数按注册完成时间筛选，申请相关指标按申请提交时间筛选；审核状态取统计截至日快照，UTC+0、T+1更新。
- **数值格式**：数量为千分位整数，比率保留1位小数，零分母显示“—”。缺失渠道来源归入“未归因”，并计入总量。

## 4. 筛选与搜索

统计范围支持累计、近30天、近7天，同时支持项目、渠道、招募单状态和关键词。关键词匹配渠道名、项目名/编号、招募单名/编号；多个条件取交集。顶部、主表、展开表、抽屉与导出同步使用筛选结果，注册和申请分别使用各自的事件时间及来源归因。

修改筛选或搜索后返回第1页并收起展开行。切换汇总维度保留筛选和主表排序，返回第1页并收起展开行；“重置”恢复默认筛选、通过人次降序和第1页。

## 5. 排序与Tooltip

主表的注册人数、申请人次、通过人次、待审核人次、审核通过率支持排序；展开表的招募单数、注册人数、申请人次、通过人次、审核通过率支持排序。

默认通过人次降序。首次点击新的字段按降序，再次点击切换升序，箭头标识当前字段和方向。主表先对全部筛选结果排序再分页；展开表仅排序当前父行。数值相同时按通过人次、申请人次降序，再按名称升序；无分母的比率排在末尾。

顶部指标及表头旁展示说明图标，悬停、键盘聚焦或点击显示定义、去重规则和计算公式。注册人数的tooltip说明首次注册、按用户ID去重、包含未申请用户、来源归因和注册时间口径。说明图标独立于排序按钮，点击说明不触发排序。

## 6. 点击与下钻

- 点击“+”或名称展开对应项目/渠道，再次点击收起，允许多行同时展开。
- 主表“查看明细”打开当前渠道或项目下的招募单×渠道记录；展开表“招募单明细”限定为当前项目×渠道。
- 抽屉展示招募单名称、编号、项目、状态、渠道、注册人数、申请人次、通过人次、待审核人次、审核通过率及顶部合计。
- 只有注册、尚无申请的渠道仍可展开和查看明细，申请人次显示0，审核通过率显示“—”。
- 关闭按钮、遮罩或Escape关闭抽屉，保留原筛选、排序、展开状态和页码。

## 7. 分页、导出与结果状态

主表每页10行，合计行不占分页数量。导出全部筛选结果并保留当前排序，包含统计截至日、统计范围、时间口径、汇总维度、项目/招募单/渠道信息、注册人数、申请人次、通过人次、拒绝人次、待审核人次、审核通过率及筛选条件；抽屉可导出当前明细。

没有匹配的注册或申请记录时显示空结果和重置入口，并禁用导出。注册和申请均为0的渠道保留在渠道汇总中，展开和明细入口禁用。
